Icons used by SNOWY OWL (names match the lucide icon set).

Put your own lucide files (same names) in  www/assets/icons/  (or in this folder) and run:  npm run build
The build copies them into the sprite inside www/index.html, so there is no network and no font.
If a file is missing, the icon already in the page is kept, so nothing ever disappears.

snooze.svg (alarm clock with zzz) is custom, it is not in lucide: keep the one supplied here.
Files must be 24x24 stroke icons (lucide / heroicons-outline style).
